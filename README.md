# Sample_Size

В данном репозитории хранится проект, посвящённый рассчёту размера выборки для АВ теста методом симуляций Монте-Карло, выполненный в рамках курса "Симулятор аналитика" от Karpov.Courses

## Задача 1
Коллеги из ML-отдела разработали новый алгоритм, рекомендующий пользователям интересные посты с целью увеличить количество просмотров и лайков на пользователя:

* Алгоритм добавляет пользователям 1-2 просмотра
* Вероятность того, что он сработает, составляет 90%
* Если у пользователя меньше 50 просмотров, то алгоритм не сработает

**Цель работы:** Оценить, сможем ли мы обнаружить различия в среднем количестве лайков на пользователя, проведя симуляцию Монте-Карло.

**Этапы работы:**
1) На основе распределений из АА-теста симулируем просмотры и пользовательские CTR.
2) Размер выборки - количество пользователей за 1 неделю в период АА-теста.
3) Пользователей разбиваем на две группы в соотношении 50/50.
4) На одной из групп симулируем эффект от работы алгоритма на просмотры: group_B_views + ((1 + np.binomial(n=1, p=0.5, size=размер_выборки)) * np.binomial(n=1, p=0.9, size=размер_выборки) * (group_B_views >= 50)).
5) Количество симуляций задайте не меньше 20000.
6) Сравнить количества лайком t-тестом с поправкой Уэлча на неравные дисперсии (equal_var=False). Уровень значимости 0.05.

**Результат:** Вероятность обнаружить эффект, когда он есть (мощность) составила 26.65%, это мало, меньше, чем желаемые 80%.

## Задача 2
Алгоритм был подкорретирован, теперь он срабатывает на пользователях с числом просмотров от 30 и выше.
**Цель работы:** Рассчитать мощность для нового алгоритма

**Этапы работы:**
1) Для тех же данных симулируем эффект group_B_views2 = group_B_views + ((1 + rng.binomial(1, 0.5, N)) * rng.binomial(1, 0.9, N) * (group_B_views >= 30))
2) Проведём также 20000 симуляций, рассчитывая на каждой итерации p-value

**Результат:** Мощность составила 42.95%
